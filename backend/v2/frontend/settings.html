Admin area

For whoever runs the server: the settings this installation can change while it is running, a restart button, and what the tool could not do — texts it failed to parse, mod lines it could not resolve, and how far a localized data set has fallen behind English. Nothing here is needed to play.

One plaintext password from a file on the server (default: admin). This is a partition, not a security mechanism — it keeps the ordinary user out of a view that is none of their business.

Server settings

The settings this installation can change while it is running. They are written to a file in the /config volume, and that file wins over the values the container was started with. Nothing secret can be set or read here.

Update to a newer version

Pulls the newest code on the server and rebuilds the container. This needs a small script on the host — the tool cannot do it by itself, and deliberately has no access to the host's Docker daemon.

Output from the host, filtered: lines naming something that could be a credential are dropped and credentials inside a URL are masked. That is a filter, not a guarantee — a bare token in a line that names nothing passes it.
